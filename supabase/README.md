# supabase 폴더

윗블의 데이터베이스 설계와 보안 규칙입니다.

| 파일 | 내용 |
|---|---|
| `001_schema.sql` | 표 12개, 보안 규칙(RLS), 앱에서 부르는 함수 6개 |
| `002_email_consent.sql` | 동의 기록에 이메일(선택) 항목 추가 |
| `test_security.sql` | 보안 규칙 시험. 가짜 사용자로 "보면 안 되는 걸 볼 수 있는지" 확인 |

## 처음 설정하는 법

1. Supabase 대시보드에서 프로젝트를 열고, 왼쪽 메뉴의 **SQL Editor**로 가요.
2. **New query**를 누르고, `001_schema.sql` 전체를 복사해 붙여넣은 뒤 **Run**을 눌러요.
   - "Success. No rows returned"가 나오면 성공이에요.
   - 이 파일은 **처음 한 번만** 실행해요. 두 번 실행하면 "already exists" 오류가 나요. 데이터는 망가지지 않아요.
3. 이어서 `002_`, `003_` … 번호 순서대로 같은 방법으로 실행해요.
4. 다시 **New query**를 누르고, `test_security.sql` 전체를 붙여넣고 **Run**을 눌러요.
   - 결과에 **"모든 보안 시험 통과"** 가 나오면 성공이에요.
   - "시험 실패: ..."가 나오면 그 문구를 캡처해서 알려주세요.
   - 시험 데이터는 자동으로 지워져요.
5. 왼쪽 메뉴의 **Advisors > Security Advisor**에서 경고가 있는지 확인해요.

## 표 목록

| 표 | 내용 | 누가 볼 수 있나 |
|---|---|---|
| `profiles` | 이름, 한 줄 소개, 프로필 사진 | 나 + 같은 모임 멤버 |
| `user_settings` | 알림, 기본 공개 범위, 마지막 읽은 위치 | 나만 |
| `consents` | 가입 동의 기록 (수정·삭제 불가) | 나만 |
| `groups` | 모임 이름, 종류, 설명 | 그 모임 멤버 |
| `group_members` | 모임 멤버와 역할(모임장/멤버) | 그 모임 멤버 |
| `invites` | 초대 코드 (14일 뒤 만료) | 그 모임 멤버 |
| `meditations` | 묵상 | 나 + (모임에 공개했으면) 그 모임 멤버 |
| `prayers` | 기도제목, 응답 여부 | 나 + (모임에 공개했으면) 그 모임 멤버 |
| `reactions` | 공감, 함께 기도 | 그 글을 볼 수 있는 사람 |
| `highlights` | 하이라이트한 구절 | 나만 |
| `saved_verses` | 저장한 구절 | 나만 |
| `reading_days` | 성경 읽은 날 | 나만 |

로그인하지 않은 사람은 어떤 표도 볼 수 없어요.

## 앱에서 부르는 함수

| 함수 | 하는 일 |
|---|---|
| `create_group(이름, 종류, 설명)` | 모임을 만들고 나를 모임장으로 등록 |
| `create_invite(모임 id)` | 8자리 초대 코드 만들기 (모임 멤버만) |
| `invite_preview(코드)` | 초대받은 모임의 이름과 인원수 미리보기 |
| `join_group(코드)` | 초대 코드로 모임 가입 |
| `leave_group(모임 id)` | 모임 나가기. 내가 공개한 글은 나만 보기가 되고, 모임장이 나가면 다음 멤버가 모임장이 됨 |
| `delete_account()` | 회원 탈퇴. 모든 기록 삭제 |

## 나중에 바꿀 때

- `001_schema.sql`은 고치지 말고, 바꿀 내용을 `002_설명.sql` 같은 **새 파일**로 만들어 실행해요.
- 새 표를 만들면 꼭 함께 해야 할 것:
  1. `alter table ... enable row level security;` 로 보안 규칙 켜기
  2. 필요한 규칙(policy) 만들기
  3. `revoke all on 새표 from anon;`
  4. `test_security.sql`에 시험 추가
