# legal 폴더

윗블의 개인정보 관련 문서를 관리하는 곳입니다.

| 파일 | 내용 | 쓰이는 곳 |
|---|---|---|
| `privacy-policy.md` | 개인정보 처리방침 전문 | 앱 안 "개인정보 처리방침" 메뉴, 웹사이트 하단 링크 |
| `privacy-consent.md` | 가입 시 항목별 동의 문구 | 카카오 로그인 직후 동의 화면 |

## 지금 상태

- **v0.1 초안**입니다. 실제 서비스를 시작하기 전에 꼭 아래를 해 주세요.
  1. `[입력 필요]` 부분 채우기: 운영자명, 시행일, 개인정보 보호책임자 정보 (파일에서 "입력 필요"로 검색)
  2. 실제 설정과 맞는지 확인: Supabase 저장 지역을 **서울(ap-northeast-2)** 로 만들었는지, 호스팅이 Vercel인지
  3. 업체 연락처가 바뀌지 않았는지 확인: privacy@supabase.com, privacy@vercel.com
  4. 개인정보 전문가나 법률 검토 받기 (특히 민감정보와 국외 이전 부분)

## 초안에서 정한 것

- 만 14세 이상만 가입
- 카카오에서는 회원번호·닉네임(필수), 프로필 사진·이메일(선택)만 받음
  - 원래 이메일은 안 받으려 했으나, Supabase 카카오 로그인이 이메일을 항상 함께 요청해서(KOE205 오류) 카카오 비즈 앱으로 전환하고 이메일을 **선택 동의**로 바꿈 (2026-11-01)
- 민감정보 동의와 국외 이전 동의는 [필수]. 동의하지 않으면 가입 불가
- 삭제한 글은 30일 안에 백업에서도 파기
- 회원 탈퇴 메뉴: MY > 설정 > 회원 탈퇴 (앱에 아직 없음, 만들어야 함)

## 바꿀 때 규칙

1. 문서 맨 위의 **버전**과 **시행일**을 올립니다. 예: v0.1 → v1.0
2. 처리방침 14항의 "이전 버전" 목록에 이전 버전과 시행 기간을 적습니다.
3. 바뀐 내용을 시행 7일 전(이용자에게 불리하면 30일 전)부터 앱에 공지합니다.
4. 동의 항목이 바뀌면 `privacy-consent.md`의 버전도 올리고, 이용자에게 다시 동의를 받습니다.
5. git 커밋 메시지에 무엇이 바뀌었는지 적어 두면, 나중에 변경 이력을 증명할 때 도움이 됩니다.
